## Why This Works

### Binary Addressing

Each trigram is a 3-bit binary number. A 3-bit number can represent 2³ = 8 states. A cube has exactly 8 vertices. Each vertex can be addressed by 3 coordinates, each 0 or 1.

```
Binary pattern → Cube coordinates → Trigram

000 → (0,0,0) → Earth
001 → (0,0,1) → Mountain
010 → (0,1,0) → Water
100 → (1,0,0) → Thunder
011 → (0,1,1) → Wind
101 → (1,0,1) → Fire
110 → (1,1,0) → Lake
111 → (1,1,1) → Heaven
```
