## Why No Binary Correlation?

The hexagram has three bigram tiers, each operating independently:

```
BIGRAM TIER INDEPENDENCE
════════════════════════

Top Bigram:    Lines 5-6  (Uniqueness)
Middle Bigram: Lines 3-4  (Face selector)
Bottom Bigram: Lines 1-2  (Quarter)

Each tier has 4 independent combinations.
No information passes between tiers.
```

Harmonic pairs **cross bigram boundaries**:
- **1 ↔ 4:** Line 1 (bottom tier) ↔ Line 4 (middle tier)
- **2 ↔ 5:** Line 2 (bottom tier) ↔ Line 5 (top tier)
- **3 ↔ 6:** Line 3 (middle tier) ↔ Line 6 (top tier)

Since each bigram tier varies independently, cross-tier correlations **must** be 50% — anything else would violate structural independence.
