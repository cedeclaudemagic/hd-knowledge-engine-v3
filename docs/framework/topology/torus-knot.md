## Core Finding

The I Ching wheel is not a simple circle — it traces a **(2,1) torus knot**. The wave crosses zero exactly twice per cycle, creating a figure-8 pattern when projected. This topology is mathematically necessary given the cube geometry.

---

## What Is a Torus Knot?

A (p,q) torus knot wraps around a torus p times in one direction while wrapping q times in the other direction before closing.

The I Ching wheel is a **(2,1) torus knot**:
- Wraps **2 times** around the "poloidal" direction (crosses zero twice)
- Wraps **1 time** around the "toroidal" direction (completes one cycle)

## Why (2,1)?

### The "2" — Two Crossings

The cube contains two tetrahedra (Void and Material). Any complete path through the cube must:
1. Visit all void vertices
2. Visit all material vertices
3. Transition between tetrahedra twice (minimum)

**Two crossings per cycle is the minimum for complete coverage.**

### The "1" — One Complete Cycle

The path visits all 8 vertices once before returning — a Hamiltonian cycle. One complete cycle = one return to start.

---

## Topological Necessity

Given:
- 8 vertices split into 2 tetrahedra of 4 each
- Hamiltonian path (visit all vertices once)
- Return to starting vertex

**Then:** The path must cross between tetrahedra exactly twice per cycle. This is the (2,1) torus knot topology.
