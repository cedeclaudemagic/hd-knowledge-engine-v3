## Core Finding

Cross-zero gates are hexagrams where the inner and outer trigrams belong to **different tetrahedra** within the cube. They represent the transformation between void (potential) and material (form).

---

## The Two Types

| Type | Count | Direction |
|------|-------|-----------|
| **Cross-Zero Manifesting** | 16 | Void → Material |
| **Cross-Zero Dematerialising** | 16 | Material → Void |

**Total cross-zero gates:** 32 (exactly half of all 64)

## Why "Cross Zero"?

On the electromagnetic wave, the two tetrahedra occupy opposite domains:
- **Void tetrahedron:** Negative positions (-1, -2, -3, -4)
- **Material tetrahedron:** Positive positions (+1, +2, +3, +4)

Movement between tetrahedra must **cross zero** — pass through the neutral point.

```
EM Position
    +4  │  MATERIAL DOMAIN
    +3  │  (Form)
    +2  │
    +1  │
     0  │════════════════════════ ZERO CROSSING
    -1  │
    -2  │  VOID DOMAIN
    -3  │  (Potential)
    -4  │
```

## The Torus Knot Topology

Two zero crossings per cycle = **(2,1) torus knot**

The wave doesn't simply oscillate — it traces a figure-8 path that wraps around the torus twice while going around once. This is the topological signature encoded in cross-zero gate distribution.

## Relationship to Binary Complement

Cross-zero gates include all **complement pairs** (Hamming distance 3):

| Inner | Outer | Type |
|-------|-------|------|
| Earth (000) | Heaven (111) | Dematerialising |
| Heaven (111) | Earth (000) | Manifesting |
| Water (010) | Fire (101) | Dematerialising |
| Fire (101) | Water (010) | Manifesting |
| etc. | | |

**Every complement transition is a cross-zero gate.**

But not all cross-zero gates are complements — some have Hamming distance 1 or 2 while still crossing tetrahedra.

## The Pillars Gate 63 and 64

The period-2 "alternating" patterns (63, 64) are cross-zero gates:

| Gate | Pattern | Inner → Outer | Type |
|------|---------|---------------|------|
| 63 | 010101 | Water → Fire | Dematerialising |

These are the only hexagrams that alternate between tetrahedra at every bit — maximum oscillation between void and material.
