# Archive: Superseded Documents

**Historical only — see `/framework/` for current proven derivations.**

This folder contains:
- Old synthesis documents superseded by framework versions
- Completed briefs
- Duplicate files consolidated elsewhere

---

## Why Archive Instead of Delete

1. Preserves git history connections
2. May contain unique insights or phrasings
3. Documents the evolution of thinking

---

## When to Use Archive

Move a file here when:
- A newer, better version exists elsewhere
- The content has been consolidated into framework
- The file is a completed brief or task document
