## Derivation Notes

### Binary Pattern Reading
Binary patterns read bottom-to-top:
- Lines 1-2 form lower trigram
- Lines 3-4 form middle
- Lines 5-6 form upper trigram
- 1 = yang (solid line), 0 = yin (broken line)

### Position Calculation
Each trigram has an electromagnetic position:
- Heaven (111) = -4
- Earth (000) = +4
- Fire (101) = -2
- Water (010) = +2
- Thunder (100) = +1
- Mountain (001) = +3
- Wind (011) = -1
- Lake (110) = -3

### Movement Type Classification
- **Standing Wave**: Inner position = Outer position (same trigram)
- **Same-Phase**: Both positions same sign (both positive or both negative)
- **Cross-Zero**: Positions have opposite signs (one positive, one negative)
  - **Manifesting**: Negative → Positive (void to form)
  - **Dematerialising**: Positive → Negative (form to void)

### Palindrome Detection
A binary pattern is palindromic if it reads the same forward and backward:
- 111111 (Gate 1) - palindrome
- 000000 (Gate 2) - palindrome
- 010010 (Gate 29) - palindrome
- 101101 (Gate 30) - palindrome
- 101010 (Gate 63) - palindrome
- 010101 (Gate 64) - palindrome

### Period Classification
Based on smallest repeating unit in binary pattern:
- Period 1: Pattern is constant (Gates 1, 2)
- Period 2: Pattern alternates (Gates 63, 64)
- Period 3: Pattern repeats every 3 (most standing waves)
- Period 6: No repetition (most gates)
