## Key Principles

### 1. Everything is Oscillation
The wave moves between void (-) and material (+) domains. All 64 hexagrams are positions or movements on this wave.

### 2. Trigrams Define Function
Each trigram has a specific electromagnetic function (gate, flow, storage, pole). The combination of inner and outer trigrams determines hexagram behavior.

### 3. Lines Track the Wave
Lines 1-3 belong to the inner trigram; Lines 4-6 to the outer. The 3/4 transition is the shift from internal to external expression.

### 4. Centres are Transformers
Each centre transforms electromagnetic energy in specific ways. Motor centres generate; awareness centres process; pressure centres drive.

### 5. Types Emerge from Configuration
The four types (Manifestor, Generator, Projector, Reflector) emerge from which centres are defined and connected.
