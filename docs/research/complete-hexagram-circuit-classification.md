## The Complete Circuit Address System

Every hexagram has a unique address:

```
[Inner Position] → [Outer Position] = [Vector Type]
```

**Vector Types:**
- **Manifest:** negative → positive (toward matter)
- **Demanifest:** positive → negative (toward void)
- **Material Circulation:** positive → positive
- **Void Circulation:** negative → negative
- **Standing Wave:** same → same

**Examples:**
- Gate 11: (-4) → (+4) = Full Manifestation
- Gate 12: (+4) → (-4) = Full Demanifestation
- Gate 63: (-2) → (+2) = Middle Manifestation
- Gate 39: (+3) → (+2) = Material Circulation
- Gate 50: (-1) → (-2) = Void Circulation
- Gate 1: (-4) → (-4) = Standing Wave (Source)

## Implications for the 384 Lines

Every line of every hexagram can now be addressed by:

1. **Hexagram Type** — cross-zero, same-phase, or doubled
2. **Inner Position** — which wave position does line 1 enter
3. **Outer Position** — which wave position does line 6 complete
4. **Line Number** — which stage of transit (1-6)
5. **Trigram Assignment** — inner (1-3) or outer (4-6)
6. **Trigram Line** — position within the trigram (1-3)

**The 3→4 junction is the Monopole moment in cross-zero hexagrams** — where energy actually transits through zero.

In same-phase hexagrams, the 3→4 junction is still a threshold between inner and outer expression, but no fundamental transformation occurs.

In doubled hexagrams, the 3→4 junction marks the shift from internal to external expression of the same pure state.
