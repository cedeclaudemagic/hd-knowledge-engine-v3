## Comparative Analysis

### Cross-Zero Transitions: MODE SHIFT
The 3→4 crossing in transformational gates changes **what type of energy is operating**:
- Internal state → External function
- Knowing → Acting
- Receiving → Transmitting

### Same-Phase Material Transitions: POLARITY FLIP
The 3→4 crossing in material circulation gates changes **direction within matter**:
- Taking → Giving
- Inflating → Contracting
- Engaging → Withdrawing

### Same-Phase Void Transitions: RELATIONAL REORIENTATION
The 3→4 crossing in void circulation gates changes **how potential relates**:
- Self-focus → Other-focus
- Connecting → Examining
- Participating → Observing

## The Key Distinction

**Cross-zero gates:** Line 3 completes inner trigram; Line 4 begins outer trigram **in a different domain**. The transition crosses the Monopole — fundamental transformation.

**Same-phase gates:** Line 3 completes inner trigram; Line 4 begins outer trigram **in the same domain**. The transition is a threshold, not a transformation — the energy reorients but doesn't change nature.

This explains why same-phase transitions often show **reversals** (Greed→Generosity) — they're navigating the same territory from opposite directions, not entering new territory.
