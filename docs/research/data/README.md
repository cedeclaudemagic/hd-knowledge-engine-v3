This directory contains all JSON data files generated by the analysis scripts. These files are for programmatic access and further analysis.

## Usage

These files can be loaded in Node.js:

```javascript
const fs = require('fs');
const data = JSON.parse(fs.readFileSync('planet-pairs-analysis.json', 'utf8'));

// Access pair data
console.log(data.pairCounts['Moon/Mars']); // 22

// Find all rare pairs
const rarePairs = Object.entries(data.pairCounts)
  .filter(([_, count]) => count === 1);
```
