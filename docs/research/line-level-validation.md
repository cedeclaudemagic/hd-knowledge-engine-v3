## Language Type Distinctions

### State Language (Standing Waves)
- Describes **being at a position**
- No movement verbs
- Quality and character emphasis
- Examples: clarity, receptivity, creativity, objectivity

### Action Language (Circulators)
- Describes **doing within a domain**
- Movement and process verbs
- Direction without transformation
- Examples: defending, structuring, progressing, fusing

### Transformation Language (Cross-Zero)
- Describes **becoming something else**
- Crossing, releasing, building vocabulary
- Domain change explicit
- Examples: withdrawal, purification, metamorphosis, assimilation
