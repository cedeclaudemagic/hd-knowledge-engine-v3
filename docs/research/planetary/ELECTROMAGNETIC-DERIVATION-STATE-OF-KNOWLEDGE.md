## Part 4: Ruled Out — Nuclear Trigrams

### Hypothesis

Nuclear trigrams are classical I Ching structure:
- Lower nuclear: lines 2-3-4 form a trigram
- Upper nuclear: lines 3-4-5 form a trigram
- Together they create the "nuclear hexagram" — hidden structure within

**Test:** Do cross-zero gates with identical (position, line, gateType) but different nuclear trigrams have different exalting planets?

### Methodology

1. **Initial test:** Add nuclear trigrams to prediction key
   - Result: Accuracy improved from 43.7% to 76.3%
   - Problem: 142 groups for 190 items = ~1.3 items per group (overfitting)

2. **Leave-one-out cross-validation:** For each item, train on all OTHER items, predict that one
   - This prevents overfitting by ensuring we only predict unseen data

3. **Permutation test:** Shuffle nuclear labels randomly 100 times
   - If nuclear carries signal, actual accuracy > shuffled accuracy
   - If nuclear is noise, actual accuracy ≈ shuffled accuracy

### Results

| Metric | Without Nuclear | With Nuclear |
|--------|-----------------|--------------|
| Leave-one-out accuracy | 17.9% | **3.2%** |
| Change | baseline | **-14.7 pp WORSE** |

| Statistical Test | Result |
|------------------|--------|
| Actual accuracy | 3.2% |
| Mean shuffled accuracy | 3.0% |
| Std dev shuffled | 1.4% |
| **Z-score** | **0.09** |

### Interpretation

- Z-score of 0.09 means nuclear trigrams are **indistinguishable from random noise**
- Adding nuclear information makes predictions **worse** due to data fragmentation
- The initial "improvement" was **pure overfitting**

### Conclusion

**Nuclear trigrams do NOT carry planetary information.**

Classical I Ching internal hexagram structure is not the source of cross-zero variance. The missing factor lies elsewhere.

## Part 5: Ruled Out — Russell Wave Mechanics

### Hypothesis

Walter Russell's wave mechanics describe matter/energy cycles through:
- **Octave positions** — specific points in the wave cycle
- **Phase relationships** — compression vs expansion, charging vs discharging
- **Locked potentials** — stable configurations at specific wave positions

If planets correspond to Russell's wave positions, cross-zero gates might require knowing:
- Which OCTAVE of transformation is occurring
- The PHASE relationship (not just that transformation is happening)
- The DIRECTION of charge (compression vs expansion)

### Properties Tested

Using the existing Russell-trigram mapping (from `russell-locked-potentials-ring.js`):

| Property | Description | Tested Via |
|----------|-------------|------------|
| Axis Transition | POLES→FLOW, GATES→CONTAINERS, etc. | 16 unique transitions |
| Zone Transition | Radiating→Generating, Zero Crossing→Local Ground, etc. | 17 unique transitions |
| Gate Position | Is Thunder/Wind (±1) the inner or outer trigram? | inner, outer, none |
| Domination Transition | CUBE→SPHERE, Dematerialising→Materialising, etc. | Phase direction |
| Amplitude | Gap size between inner and outer positions | 1-8 range |

### Results

| Model | Leave-One-Out Accuracy | vs Baseline |
|-------|------------------------|-------------|
| Baseline (pos, line, gateType) | 17.9% | — |
| + Axis transition | 0.0% | **-17.9 pp** |
| + Zone transition | 8.4% | -9.5 pp |
| + Gate position | 14.7% | -3.2 pp |
| + Domination transition | 8.4% | -9.5 pp |
| + Amplitude | 0.0% | **-17.9 pp** |
| Full Russell (no gateType) | 0.0% | **-17.9 pp** |
| Inner+Outer trigrams + line | 0.0% | **-17.9 pp** |

### Statistical Test

| Metric | Value |
|--------|-------|
| Actual accuracy (trigrams) | 0.0% |
| Mean shuffled accuracy | 6.2% |
| Std dev shuffled | 2.1% |
| **Z-score** | **-2.96** |

A Z-score of -2.96 means Russell properties are **significantly WORSE than random noise**.

### Interpretation

Russell's wave mechanics properties provide **no predictive value** for cross-zero planetary assignments. Adding any Russell property to the model either:
- Makes no difference, or
- Makes predictions **worse**

This is not weak signal — it's negative signal. The data actively contradicts the hypothesis that Russell wave positions explain transformation-layer variance.

### Conclusion

**Russell wave mechanics do NOT explain cross-zero variance.**

The transformation layer's planetary assignments cannot be derived from:
- Electromagnetic position
- Line number
- Gate type
- Nuclear trigrams
- Russell wave properties
- Trigram identity

### Status

**RULED OUT.**

## Methodology Notes

### What Worked

1. **Stratification by gate type** — revealed the structural boundary between derivable and non-derivable
2. **Leave-one-out cross-validation** — distinguished real signal from overfitting
3. **Permutation testing** — established statistical significance baseline
4. **Iterative model building** — each version revealed what features matter

### What Didn't Work

1. **Generic rules** (v1) — 19.7% accuracy, rules don't transfer between positions
2. **Assuming nuclear trigrams carry information** — initial "improvement" was overfitting
3. **Overall accuracy targets** — 70% is structurally impossible due to cross-zero boundary

### Key Insight

The 70% accuracy target was asking the wrong question. The right question was: **"Where does electromagnetic derivation work and where does it fail?"**

Answer: It works perfectly at standing waves, partially at same-phase gates, and fails at cross-zero gates. This is information about the system's structure, not model failure.
