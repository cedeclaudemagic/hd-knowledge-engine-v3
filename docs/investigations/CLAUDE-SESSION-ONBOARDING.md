Every investigation must document:
1. Question (precisely stated)
2. Hypothesis (testable)
3. Method (how tested)
4. Results (with numbers)
5. Classification
6. Connection to framework

## Questions to Ask Yourself

Before concluding any investigation:

1. ✓ Is the mechanism explicit (not just correlation)?
2. ✓ Is this structure necessary (no alternatives work)?
3. ✓ Does it connect to the proven framework?
4. ✓ Are all exceptions explained?
5. ✓ Would another investigator reach the same conclusion?

If any answer is "no," the investigation is incomplete.

## Getting Help

If stuck:
1. Check `/docs/investigations/historical/` — has this been tried before?
2. Review `/docs/framework/` — is there a related proven structure?
3. Consult the methodology — are you following the pattern?
4. Document what you tried — even failures are valuable
