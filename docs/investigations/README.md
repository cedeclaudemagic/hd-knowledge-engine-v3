# Investigations: Outstanding Work

**Everything in this directory is under active investigation.**

The pressure remains. These are not failures — they are open questions. The work continues until geometric necessity is found or definitively ruled out.

---

## What "Outstanding" Means

An investigation is OUTSTANDING when:
1. A geometric derivation has not yet been found
2. Previous attempts have not succeeded (but haven't proven impossibility)
3. The question remains live
4. Pressure continues to find the underlying structure

## Active Investigations

Each folder in `active/` contains an `INVESTIGATION-STATUS.md` file that tracks:
- Current question
- What's been tried
- Next approaches
- Success criteria

---

## Boundaries vs Conclusions

The `boundaries/` folder contains findings about **current limits** — NOT permanent conclusions.

A boundary means: "We have not yet found a geometric derivation for this."

It does NOT mean: "This is forever underivable."

The distinction matters. Boundaries are pressure points. They tell us where to push next.

---

## Historical Investigations

The `historical/` folder preserves previous investigation attempts. This is valuable because:
1. It prevents repeating failed approaches
2. It documents what's been tried
3. It may contain insights for future investigators

---

## Adding New Investigations

When starting a new investigation:

1. Create a folder in `active/`
2. Add an `INVESTIGATION-STATUS.md` using the template
3. Begin documenting approaches and findings
4. Move to `boundaries/` if a limit is confirmed
5. Move to `historical/` when complete (success or proven impossible)
