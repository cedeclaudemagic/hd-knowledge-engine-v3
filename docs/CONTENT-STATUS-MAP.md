As of Version 2.0, works are identified by their **electromagnetic position** rather than arbitrary book numbers. Each position reflects the work's function in the complete architecture:

```

──────────────────────────────────        ────────────────────────────────────

Position -4: SOURCE                       Position +4: SINK
  The Geometry of Consciousness             The Living Oracle

Position -3: CAPACITANCE                  Position +3: INDUCTANCE

  The Shape of Change                       Electromagnetic Interpretations

Position -1: GATE-OUT                     Position +1: GATE-IN
  The Proof                                 The Wave
```

**Why This Matters:** The position reflects what the work DOES:
- Position -4 (SOURCE): Where everything originates — first principles derivation
- Position -3 (CAPACITANCE): Stored potential — the deep architecture beneath
- Position -2 (VOLTAGE): Driving pressure — the "why should I care?"
- Position -1 (GATE-OUT): Release to form — proofs made formal
- Position +1 (GATE-IN): Entry point — where readers enter
- Position +2 (CURRENT): Sustained flow — framework applied to all 64 gates
- Position +3 (INDUCTANCE): Crystallised form — HD structures derived
- Position +4 (SINK): Complete reception — practical embodiment in use
