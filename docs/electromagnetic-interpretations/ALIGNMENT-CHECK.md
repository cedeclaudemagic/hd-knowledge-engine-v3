# Alignment Check — Quick Reference

*Use this document to quickly assess alignment between I-Ching, Ra Uru Hu, and EM Framework*

---

## The Five-Layer Check

For any line, verify alignment at each layer:

### Layer 1: Gate Type
| Gate Type | Expected Language | Check |
|-----------|-------------------|-------|
| **Standing Wave** | State, being, holding | Does text describe a position/quality? |
| **Cross-Zero** | Transformation, crossing, becoming | Does text describe change/journey? |
| **Same-Phase** | Action, circulation, process | Does text describe doing/moving? |

### Layer 2: Line Position
| Line | Position | Expected Theme |
|------|----------|----------------|
| 1 | Entry-Inner | First contact, initial, hidden, beginning |
| 2 | Development-Inner | Building, growing, structuring, preparing |
| 3 | Completion-Inner | Peak of origin, pre-threshold, acceptance |
| 4 | Entry-Outer | First contact with destination, arrival, new start |
| 5 | Development-Outer | Building in new domain, establishing, growing |
| 6 | Completion-Outer | Peak/completion, warning about excess, cycle-end |

### Layer 3: Trigram Position
| Position | Function | Expected Imagery |
|----------|----------|------------------|
| -4 (Heaven) | Source | Creative, initiating, potential, hidden |
| -3 (Lake) | Capacitance | Joy, openness, stored potential |
| -2 (Fire) | Voltage | Clarity, pressure, illumination |
| -1 (Wind) | Gate OUT | Penetration, dissolution, release |
| +1 (Thunder) | Gate IN | Shock, arousal, manifestation entry |
| +2 (Water) | Current | Flow, danger, depth, movement |
| +3 (Mountain) | Inductance | Stillness, stopping, stored form |
| +4 (Earth) | Sink | Reception, form, density, completion |

### Layer 4: Vector Direction
| Direction | Movement | Expected Theme |
|-----------|----------|----------------|
| **Manifesting** (- → +) | Void to Matter | Building, creating, solidifying |
| **Dematerialising** (+ → -) | Matter to Void | Releasing, dissolving, returning |
| **Static** (same → same) | Holding position | Maintaining, anchoring, being |

### Layer 5: Polarity Check
| Line Polarity | Character |
|---------------|-----------|
| **YANG** | Active, initiating, expressing |
| **YIN** | Receptive, responding, containing |

## Quick Alignment Patterns

### Standing Waves — What to Look For

**Line 1:** Hidden/concealed state (not yet expressed)
**Line 2:** Developing/emerging state
**Line 3:** Internal peak with tension for expression
**Line 4:** First external expression (often uncertain)
**Line 5:** Developed external expression
**Line 6:** Peak expression with warning against excess

**Example Pattern (Gate 1):**
- Line 1: Hidden dragon → Hidden state at Source
- Line 6: Arrogant dragon → Over-claiming at peak

### Cross-Zero — What to Look For

**Lines 1-3:** Origin domain themes
**Line 3→4:** Zero-crossing language (change, transition, threshold)
**Lines 4-6:** Destination domain themes

**Example Pattern (Gate 11):**
- Lines 1-3: Heaven themes (potential, attunement, acceptance)
- Lines 4-6: Earth themes (arrival, distribution, transience)

### Symmetry Pairs — What to Look For

Paired gates (same trigrams, reversed) should show:
- Same imagery with inverted meanings
- Opposite directions through same terrain
- Complementary warnings at completion

**Example (Gates 63/64):**
- Gate 63.1: "Tail in water. No blame" (entering current)
- Gate 64.1: "Tail in water. Humiliating" (leaving current)

## Red Flags — Potential Misalignment

### Position Mismatch
- Line describes "entry" but position is development/completion
- Line describes "action" but gate type is standing wave
- Line describes "transformation" but gate is same-phase

### Polarity Conflict
- YANG line with entirely passive/receptive text
- YIN line with entirely active/initiating text
- (Note: some tension is normal; complete reversal is flag)

### Planetary Inconsistency
- Mars exalted at Source (-4) positions (usually detriment)
- Moon detriment at entry positions (usually exalted)
- Check if there's a reason or if it's anomaly

## Alignment Rating Scale

| Rating | Criteria |
|--------|----------|
| **EXCELLENT** | All 5 layers align; imagery precisely maps to EM position |
| **STRONG** | 4/5 layers align; minor variations in emphasis |
| **MODERATE** | 3/5 layers align; notable tension in interpretation |
| **WEAK** | 2/5 layers align; significant conflict between frames |
| **CONFLICT** | Direct contradiction between sources |

## Common Patterns by Gate Type

### Poles Axis (Heaven ↔ Earth)
- Full amplitude (8)
- "Great" and "small" language
- Complete transformation themes

### Storage Axis (Lake ↔ Mountain)
- Capacitance/Inductance
- Stored potential vs stored form
- Joy/stillness contrast

### Flow Axis (Fire ↔ Water)
- Pressure/movement
- Voltage/current
- Clarity/depth contrast

### Gates Axis (Wind ↔ Thunder)
- Threshold crossing
- Penetration/arousal
- Open/close dynamics

## Planetary Quick Reference

### Typically Exalted At:
- **Moon:** Entry positions, timing, receptivity
- **Venus:** Threshold/transition, harmony, values
- **Mercury:** Development positions, detail, strategy
- **Sun:** Peak/completion, illumination, authority
- **Jupiter:** Expansion, principle, patience
- **Saturn:** Structure, discipline, limits

### Typically Detriment At:
- **Mars:** Source positions (disrupts potential)
- **Uranus:** Stable positions (disrupts structure)
- **Pluto:** Completion positions (over-transformation)
