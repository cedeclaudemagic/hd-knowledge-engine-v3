## Project Overview

This project interprets every line of the I-Ching/Rave I-Ching through the electromagnetic framework, comparing:
- **I-Ching** (Wilhelm/Baynes translation)
- **Ra Uru Hu** (Black Book & White Book)
- **Electromagnetic Framework** (Four Axes, Gate Types, Line Positions)

Each gate interpretation assesses alignment between these three sources and flags patterns of interest.

### Key Patterns Discovered

#### 1. **Symmetry Pairs Show Perfect Inversion**
- Gates 11/12 (Poles axis): Same imagery, opposite meanings
- Gates 63/64 (Flow axis): "Tail in water" / "Head in water" inverts
- Gates 5/6 (Source-Current axis): Same amplitude (6), opposite direction and tone
  - Gate 5 "Waiting" (manifesting, patient nourishment)
  - Gate 6 "Conflict" (dematerialising, friction/tension)

#### 2. **Standing Waves Use Body/Progressive Imagery**
- Gate 1: Hidden → Flying → Arrogant dragon
- Gate 2: Hoarfrost → Structure → Fighting dragons
- Gate 51: Shock progression through 6 phases
- Gate 52: Body stillness (toes → calves → hips → trunk → jaws → noblehearted)
- Gate 57: Penetration imagery (under bed appears Lines 2 and 6 with opposite outcomes)
- Gate 58: Joy progression (contented → sincere → depleted → focused → defended → seductive)

#### 3. **Cross-Zero Gates Use Journey/Threshold Language**
- Pre-threshold (Line 3): Always about accepting the crossing
- Post-threshold (Line 4): Always about first contact with new domain

#### 4. **Same-Phase Gates Use Circulation Language**
- Material (+ → +): Action within form, practical progression
- Void (- → -): Action within potential, strategic movement

#### 5. **Position Determines Completion Quality**
| Position | Completion Character | Example |
|----------|---------------------|---------|
| Source (-4) | Noble, creative | Gate 1.6: Arrogant dragon (warning) |
| Sink (+4) | Receptive, yielding | Gate 2.6: Dragons fight (tension) |
| Current (+2) | **IMPRISONMENT** | Gate 29.6: Bound in prison |
| Voltage (-2) | Strategic deployment | Gate 30.6: King sends to chastise |
| Gate-IN (+1) | Don't push further | Gate 51.6: Don't go ahead |
| Gate-OUT (-1) | Don't release further | Gate 57.6: Loses property |
| Inductance (+3) | Noble peace | Gate 52.6: Noblehearted stillness |
| Capacitance (-3) | Seductive attraction | Gate 58.6: Seductive joyousness |

**Critical Finding:** Current (+2) is uniquely problematic at completion — flow that cannot move becomes imprisonment. All other positions have more positive completion potential.

#### 6. **Planetary Patterns**
- **Mars:** Often detriment at Source positions (disrupts potential); mixed at storage positions
- **Moon:** Often exaltation at entry positions (timing) and Gate-OUT (intuition)
- **Venus:** Supports threshold/entry positions; central to Capacitance (joy)
- **Sun:** Supports illumination/awareness at peak positions

#### 7. **Gate Type Language Patterns**
| Type | Language Character | Example |
|------|-------------------|---------|
